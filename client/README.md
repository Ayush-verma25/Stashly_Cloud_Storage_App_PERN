# Stashly client

The client is a React application built with Vite.

1. Run `npm install` in this directory.
2. Copy `.env.example` to `.env` and configure `VITE_BASE_URL` for the API.
3. Use `npm run dev` for local development, `npm run lint` for linting, and
   `npm run build` for a production bundle.

See the [project README](../README.md) for server configuration and production
deployment requirements.
